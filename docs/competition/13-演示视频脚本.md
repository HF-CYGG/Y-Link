# Y-Link——智能库存与订单协同管理系统演示视频脚本

## 成片说明

- 成片时长 4 分 50 秒（290 秒）。素材来自本地 Docker 和 Chrome 原生 viewport，共 33 张正式图和 13 帧交互素材。
- 管理端、供应端、客户端按段落快速切换；等待、列表加载和无关滚动局部加速，关键提交和状态变化保持原速。
- 采用分段剪辑，不作一镜到底表述；画面不显示密码、Cookie、Token、真实域名或个人信息。
