# Y-Link——智能库存与订单协同管理系统演示视频脚本

## 录制约束

- 总时长 4 分 50 秒（290 秒），成片不超过 5 分钟。
- 只使用本地 Docker、合成数据和独立演示账号；不打开生产环境。
- 管理端、客户端、供应端各保留一个浏览器会话，按段落快速切换；登录、列表加载和无关滚动可用 1.5—2 倍速，关键提交和状态变化保持原速。
- 密码输入、Cookie、Token、真实域名和个人信息不入画。字幕使用简体中文。

## 预置数据编号

| 编号 | 用途 |
| --- | --- |
| `P-1001` / `SKU-1001-A` | 多规格商品“鲜奶”，标签 `T-FRESH`，库位 `A-01-01` |
| `IN-20260920-001` / `V-2026-001` | 待核验供应送货单和核验码 |
| `PO-20260920-001` | 待核销预订单，包含一件 `SKU-1001-A` |
| `PO-20260920-002` | 已取消预订单，用于展示预占释放 |
| `PO-20260920-003` / `RT-20260920-001` | 已核销订单和退货记录 |
| `FB-20260920-001` | 客户反馈会话，含一条客服回复和一条内部备注 |

| 时间 | 画面与操作 | 旁白/字幕 |
| --- | --- | --- |
| 0:00—0:18 | 片头；展示作品名、三个 Web 会话和本地 Docker 地址。 | “这是 Y-Link 智能库存与订单协同管理系统。本片演示管理、供应和客户端的 Web 流程。” |
| 0:18—0:42 | 管理端登录，快速查看工作台统计、近期单据和库存概览。 | “管理端从工作台进入商品、库存、订单和客服模块，统计数据来自本地合成库。” |
| 0:42—1:10 | 打开 `P-1001`，查看标签 `T-FRESH`、规格矩阵和 `SKU-1001-A`；切到商城展示字段。 | “产品、标签和多规格 SKU 共用主数据。下单时只允许选择有效规格，历史订单保存快照。” |
| 1:10—1:38 | 切换供应会话，查看或提交 `IN-20260920-001`；再切回管理端，用 `V-2026-001` 核验。提交按钮和列表等待可局部加速。 | “供应方提交带预计送达时间和明细的送货单。管理端核验后写入入库记录和库存流水。” |
| 1:38—2:06 | 打开库位 `A-01-01` 和 `SKU-1001-A` 的余额、流水；进入盘点单，展示差异和确认。 | “库存余额、盘点差异和单据流水分别可查。盘点完成按差异记账，不直接改页面数字。” |
| 2:06—2:46 | 切到客户端：搜索商品、选规格、加入购物车、结算，提交 `PO-20260920-001`。展示订单状态和预占数量。 | “客户端从商城到结算提交预订单。服务端复核用户、SKU、数量和可用库存，并记录预占。” |

| 3:20—3:44 | 管理端新建或查看普通出库单，展示重复提交拦截、库存不足提示和历史单据。 | “普通出库在事务内校验可用量和幂等键，重复提交不会重复扣减。” |

## 剪辑标记

1. 段落之间保留角色和页面标题字幕，切换浏览器会话时不显示地址栏中的敏感参数。
2. 仅对登录等待、列表翻页、无关滚动和 Docker 日志使用局部加速；状态提交、错误提示和结果列表使用原速。
3. 迁移失败信息必须与 `07-测试文档.md` 的实际结果一致，不能替换为“迁移成功”。
