# Y-Link——智能库存与订单协同管理系统概要设计说明书

## 1. 分层结构

```text
管理端 Web ─┐
客户端 Web/H5 ├─ Nginx ─ Express API ─ TypeORM ─ SQLite / MySQL
供应端 Web ─┘                    │
                           上传、审计、通知、迁移控制
```

前端使用 Vue 3、TypeScript、Pinia、Vue Router、Element Plus；后端使用 Express、TypeScript、TypeORM。onebox 将静态前端、反向代理和后端服务放入同一容器。

## 2. 模块划分

| 模块 | 前端入口 | 后端职责 |
| --- | --- | --- |
| 商品与商城 | 管理产品/SKU；客户端商城 | 主数据、SKU 有效性、商城快照 |
| 入库供应 | 供应送货；管理端核验 | 送货单、核验码、入库和库存写入 |
| 库存与出库 | 库存、盘点、普通出库、报表 | 可用量校验、库存单据、流水、导出 |
| O2O | 购物车、结算、订单、核销 | 预占、取消、核销、退货、正式出库关联 |
| 客服与治理 | 反馈、客服工作台、系统设置 | 会话、附件、角色权限、审计、配置 |

## 3. 接口边界

| 接口域 | 典型输入 | 典型输出 | 权限边界 |
| --- | --- | --- | --- |
| 供应送货 | `expectedArrivalAt`、`items[]`、备注 | 单号、核验码、状态 | 供应方认证；单据归属校验 |
| 入库核验 | 核验码 | 已核验单据、入库结果 | 管理认证、权限、CSRF |
| 预订单 | 请求键、提货人、订单类型、明细 | 订单号、状态、库存预占结果 | 客户端认证；订单归属校验 |
| 核销/退货 | 核验码或订单标识、处理信息 | 新状态、关联单据 | 管理认证、权限、CSRF |
| 客服会话 | 会话标识、消息、指派/备注 | 会话详情、消息列表 | 客户端或客服身份分别校验 |

后端路由在参数校验后调用服务层；服务层负责事务、状态机、库存计算和审计。公开健康检查只返回必要运行状态，不返回数据库拓扑。

## 4. 协同控制

1. 可用库存按物理库存扣除预占量计算；创建、取消、超时、核销和退货在服务端重算并写入相应记录。
2. 普通出库、入库和盘点通过业务动作写流水，不以页面直接覆盖库存余额作为业务口径。
3. `clientUserId + clientRequestId` 为预订单请求去重键；订单快照避免主数据修改影响历史显示。
4. 数据库启动异常进入救援服务，不继续提供普通业务运行态。
