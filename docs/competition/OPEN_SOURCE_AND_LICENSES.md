# 开源组件与许可证说明

## 项目许可证

冻结基线的根目录 `LICENSE` 与 `backend/package.json` 均标注项目使用 GPL-3.0-only。提交前应保留许可证原文并对照最终源码包复核。

## 主要开源组件

| 组件 | 用途 | 许可证核对方式 |
| --- | --- | --- |
| Vue、Vue Router、Pinia | Web 界面、路由与状态 | 以锁文件与组件仓库许可证为准 |
| Element Plus、ECharts | 组件与图表 | 以锁文件与组件仓库许可证为准 |
| Express、TypeORM | API 服务与数据访问 | 以锁文件与组件仓库许可证为准 |
| SQLite、mysql2 | 数据库运行支持 | 以实际部署依赖与上游许可证为准 |
| Docker、Nginx | 容器与反向代理 | 以镜像和上游发行版许可证为准 |

## 交付要求

本清单不替代第三方依赖的完整许可证文本。打包前应执行依赖许可证清点，保留所需 notice，并确认镜像、字体、图标、演示素材的使用权限。
