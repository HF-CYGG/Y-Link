## 2. 确认事项

1. 材料范围为管理端 Web、客户端 Web/H5、供应端 Web、后端、数据库和 Docker 部署。
2. 代码事实固定为 `b149f945ad4702bc56487955ac2e2a0b8e359e2a`；材料不从当前工作树导出。
3. 演示使用本地 Docker 和合成数据，不登录生产环境；录屏不显示密码、Cookie、Token 或真实个人信息。
4. “智能”只指库存预占、状态校验、权限、审计和异常拦截等规则，不写机器学习能力。
5. 说明书保留 DOCX；另从已验收 DOCX 汇总导出设计文档 PDF 和创作过程资料 PDF。
6. 11 份 DOCX、B/C PDF、16 页 PPTX、V2 MP4 和白名单源码 ZIP 已生成；Docker 环境保持运行，浏览器素材已留存。
