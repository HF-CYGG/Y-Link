# Y-Link——智能库存与订单协同管理系统项目演示大纲

共 16 页。截图只使用本地 Docker 合成数据；每页保留 3—4 个事实要点。

## 1. 作品与演示范围

- Y-Link——智能库存与订单协同管理系统
- 管理端 Web、客户端 Web/H5、供应端 Web、后端、数据库、Docker
- 代码基线：`origin/main` 固定提交

## 2. 业务问题

- 多规格商品需要统一维护
- 送货、入库和库存余额需要同步
- 线上预订先占用库存
- 单据状态和处理记录需要追溯

## 3. 角色协同

- 管理员、操作员：商品、库存、单据、报表和治理
- 供应方：送货单提交与状态查询
- 客户端用户：浏览、预订、订单和反馈
- 客服：会话回复、指派和内部备注

## 4. 业务闭环

- 商品与 SKU 配置
- 供应送货、管理端核验入库
- 客户端预订、库存预占
- 取消、核销、退货与流水留痕

## 5. 管理工作台

- 概览、趋势和近期业务活动
- 出库开单与订单查询
- 报表筛选和导出入口
- 权限控制下的业务操作

## 6. 商品与 SKU

- 产品、标签和多规格 SKU
- 价格、图片和商城展示字段
- 当前有效规格进入下单校验
- 历史订单保存商品、规格、价格快照

## 7. 供货与入库

- 供应方填写明细、预计送达时间和备注
- 送货单、核验码和状态查询
- 管理端扫码或输入核验码
- 核验后生成入库记录与库存流水

## 8. 库存与盘点

- 商品、SKU、分类和库位查询
- 库存余额、流水和库存单据
- 盘点范围、差异和确认流程
- 扫码及导入导出入口

## 9. 客户端商城

- 可售商品和规格选择
- 购物车和结算确认
- 预订单提交和个人订单查询
- 订单状态与反馈入口

## 10. 预订单状态

- 提交时校验并预占库存
- 取消或超时释放预占
- 核销关联正式出库
- 退货按审核状态处理

## 11. 一致性控制

- 可用量按库存余额和预占量计算
- 服务端复核商品、SKU、数量和状态
- 幂等键、版本校验和事务控制写入
- 库存变化留存流水

## 12. 客服与系统治理

- 客户反馈、附件和会话消息
- 客服回复、指派、内部备注
- 用户、权限、配置和审计分开管理
- 外部通知仅展示校验与失败保护

## 13. 系统架构

- Vue 3、TypeScript、Pinia、Element Plus
- Nginx 统一入口，Express 提供 API
- TypeORM 访问 SQLite 或 MySQL
- onebox 集中静态页面、代理和后端

## 14. 数据关系

- 产品 1 对多 SKU，产品与标签多对多
- 送货单和预订单均包含明细
- 预订单核销后关联出库单
- 库存单据、盘点、入出库形成流水

## 15. Docker 与验证

- onebox 默认 SQLite，MySQL 为可选叠加服务
- 编码、Web 构建、后端构建、onebox 冒烟已通过
- 发布回归发现供应送货提交 HTTP 400 `Required`
- 数据库迁移和并发验证未通过，不展示迁移成功

## 16. 项目价值

- 商品、库存、订单和反馈有统一操作记录
- 预占、状态校验、权限和审计由规则驱动
- 演示使用本地 Docker 与合成数据
