## 3. 浏览器验收清单

| 场景 | 本地演示预期 |
| --- | --- |
| 商品与 SKU | 管理端显示产品、标签、当前 SKU；客户端可选有效规格 |
| 供应入库 | 预置或新建送货单在核验后可查询库存流水 |
| 库存盘点 | 余额、扫码、盘点、库存单据和流水均可打开 |
| 普通出库 | 合成单据可展示；库存不足、重复提交有服务端拦截 |
| 预订单 | 预占、取消释放、核销出库、退货使用不同预置订单展示 |
| 客服治理 | 反馈、回复、指派、内部备注、权限和审计可查询 |

## 4. 录制约束

浏览器录制只使用本地 Docker 和合成数据。每段从同一数据卷快照恢复；短信、邮件和 Webhook 只展示校验或失败保护。发布回归、并发、迁移和性能验证失败项必须在交付记录中保留，不能在 PPT 或视频中改写为通过。
