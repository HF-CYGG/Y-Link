# Y-Link——智能库存与订单协同管理系统

| 项目 | 内容 |
| --- | --- |
| 参赛作品名称 | Y-Link——智能库存与订单协同管理系统 |
| 参赛范围 | 管理端 Web、客户端 Web/H5、供应端 Web、后端服务、数据库与 Docker 部署 |
| 代码基线 | `origin/main`：`b149f945ad4702bc56487955ac2e2a0b8e359e2a` |
| 运行形态 | Docker onebox、默认 SQLite、可选 MySQL 服务与受控迁移流程 |
| 视频 | 本地 Docker 浏览器操作，目标 4 分 50 秒，MP4，保守控制在 200MB 内 |

系统覆盖商品规格、供应送货、入库核验、库存台账、普通出库、线上预订和客户反馈。“智能”只指库存预占、状态校验、权限门禁、审计留痕和异常拦截等规则，不包含机器学习能力。
