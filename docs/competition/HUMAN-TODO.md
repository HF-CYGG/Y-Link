# 提交前人工待办

1. 在赛事平台填写并实测评审期可访问的 Web 链接、测试账号和访问权限；未取得可靠地址前，不在材料中编造。
2. 补齐团队成员、指导教师、会议日期、计划周期和平台要求的人工字段。
3. 在本地 onebox 建立合成数据、独立演示账号和数据卷快照；完成三个 Web 登录和浏览器场景验收。
4. 处理或明确记录发布回归、数据库迁移、数据库并发和性能验证的失败项；未复验前不写通过。
5. 生成 DOCX、PPTX、MP4，逐页/逐段检查；按官网要求将已验收 DOCX 汇总导出设计文档 PDF、创作过程资料 PDF。
6. 由授权人员在最终私有 DOCX 生成阶段插入生产演示账号，并确认凭据只出现在该 DOCX 内；PDF、PPT、视频、源码和 Markdown 不含凭据。
7. 用冻结基线白名单导出源码 ZIP，完成许可证、敏感扫描、SHA-256、大小和可重建性检查。
8. 最终核对方向三上传包总大小不超过 1GB；官网视频要求为 3—5 分钟 MP4，建议 1080P/16:9，官网上限 300MB；本次按 200MB 视频上限控制。
9. 补齐团队名称、成员、指导教师、联系方式和正式生产 URL，逐项由用户确认后再上传。
