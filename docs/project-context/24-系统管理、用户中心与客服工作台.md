# Y-Link 系统管理、用户中心与客服工作台

## 适用范围

- 适用于系统配置页、用户中心、客户端用户管理、客服工作台等管理端治理模块。
- 适用于判断“这个配置在哪个页、哪个后端路由负责、客服工作台和系统配置页怎么联动”的场景。

## 最后核对来源

- `src/views/system/*`
- `src/api/modules/system-config.ts`
- `src/api/modules/user.ts`
- `src/api/modules/client-user-manage.ts`
- `src/api/modules/notification.ts`
- `backend/src/routes/system-config.routes.ts`
- `backend/src/routes/user.routes.ts`
- `backend/src/routes/client-user-manage.routes.ts`
- `backend/src/routes/customer-service.routes.ts`

## 真实入口

- 系统管理总入口：`/system/*`
- 客服工作台入口：`/system/customer-service`
- 后端入口主要分为：用户路由、客户端用户路由、系统配置路由、客服工作台路由、通知路由。

## 前端链路

- 系统配置页拆成多个 section：流水号、O2O 规则、验证码通道、客服配置、部门树、教职工目录、统一教师邀请码、通知配置等。
- 教职工目录分区顶部维护全体教师共用的自定义 8 位数字邀请码；页面只显示 `not_set/enabled/disabled` 状态和更新时间，不回显明文，设置、修改与禁用均要求 `system_configs:update` 和 `admin` 前端门禁。
- 用户中心和客户端用户管理通过共享壳层做标签页切换。
- 系统用户与客户端用户各自提供注销预检、注销、恢复和永久删除入口；两域仅共享确认弹窗与 DTO，API、服务和业务阻断规则保持隔离。列表主筛选使用服务端计算的 `accountState`，底层 `status` 仍只允许 `enabled/disabled`。
- 客服工作台负责会话列表、详情、回复、指派、状态流转、内部备注和实时订阅。
- 管理端两步验证：顶栏账号菜单“两步验证”异步挂载 `components/account/AdminMfaDialog.vue`（状态、复核密码后扫码绑定、保存恢复码、重生成、停用），二维码库按需动态加载；用户中心列表显示各账号两步验证状态，管理员可对他人执行“重置两步验证”（与重置密码同一 `users:reset_password + admin` 门禁，本人行不显示）。登录页第二步见 `42-权限、Cookie、CSRF、审计与上传安全.md`。
- 管理端通行密钥与安全密钥：登录页提供无用户名的主动密钥登录，成功后直接建立管理端会话；浏览器认证阶段可取消，最终登录验证请求发出后禁取消并阻止登录页路由离开，直到请求明确完成。顶栏账号菜单异步挂载 `components/account/AdminWebAuthnDialog.vue`，本人可查看、添加、改名或删除密钥；添加区先以“登录用途”选择直接登录或密码后验证，再在独立的“密钥类型”项选择。直接登录默认通行密钥，也可选择安全密钥类型，要求可发现凭据和用户验证；密码后验证只提供安全密钥类型，用于密码登录第二步，可由支持的认证器仅完成用户在场确认而无需 PIN 或生物验证。通行密钥可存于设备或密码管理器；USB/NFC 和实际认证器选择以浏览器及设备支持情况为准，尚无真实设备验收。添加需功能和访问 Origin 可用、当前密码，以及已开启两步验证时可用的动态码、恢复码或已绑定强凭据复核；功能关闭或能力检查失败仍允许管理已有密钥。注册最终验证和删除请求发出后弹窗需等待结果，不再允许关闭；删除 HTTP 在途还会阻止离开管理端布局，直到请求完成。注册在页面卸载后返回的结果会提示原账号，失败时先回原账号检查列表以免重复注册。一次性恢复码可逐条复制，复制全部仅用于保存；登录或复核时每次只输入一条，批量粘贴会被阻止。删除任意本人密钥会撤销该账号全部会话并要求重新登录。用户中心列表显示密钥数量，具有 `users:reset_password` 权限的管理员可为非本人账号撤销全部密钥，停用或已注销的目标也可处理，操作人会话保持有效，撤销提交后等待结果才可关闭。普通重置密码保留密钥，凭据疑似失陷时须单独撤销；原有密码及两步验证入口继续可用。服务端用途和用户验证边界详见 `42-权限、Cookie、CSRF、审计与上传安全.md`。

## 后端链路

- `system-config.routes.ts` 承接：
  - 订单流水号
  - O2O 规则
  - 客服配置
  - 验证码平台
  - 客户端部门树
  - 客户职工目录导入导出与预览
  - 统一教师邀请码状态读取、设置和禁用
- `customer-service.routes.ts` 承接：
  - 会话列表与详情
  - 回复
  - 指派
  - 状态变更
  - 结构化问题字段
  - 内部备注
  - 在线状态与 SSE

## 关键状态/字段/快照

- 系统配置不是单一 JSON，而是按 `configKey/configGroup` 维护多组配置。
- 客服工作台的关键会话字段包括：状态、优先级、负责人、内部备注、结构化问题字段、未读数。
- 客户端职工目录是独立治理对象，和客户端登录/部门树配置联动，但不等于普通用户表；目录响应不再返回个人邀请码状态，历史字段保留但不参与邀请码校验。
- 统一教师邀请码允许前导零且长期可重复使用；修改或禁用后旧码立即失效，邀请码明文不参与状态查询或页面回显。

## 权限与安全边界

- 查看系统配置依赖 `system_configs:view`，修改依赖 `system_configs:update`，部分高风险项还要求 `admin` 角色。
- 客服工作台查看依赖 `customer_service:view`，回复/指派/改状态依赖 `customer_service:reply`。
- 职工目录导入、部门树修改、验证码通道修改和统一教师邀请码写入都属于高风险治理操作，应视为后端配置变更而非纯前端表单改动。
- 账号注销/恢复要求 `users:deactivate + admin`，永久删除要求 `users:permanent_delete + admin`，两权限仅管理员拥有；永久删除还必须通过服务端永久删除密码、逐字账号确认、原因、频控和事务内关联复检。

## 常见异常与排查顺序

1. 系统配置页保存没生效：先查对应 `configKey` 写入逻辑，再查前端是否读到了旧缓存。
2. 用户中心标签切换错乱：查共享壳层 `viewKey` 和路由入口是否复用正确。
3. 客服会话列表和详情不一致：查会话详情接口是否触发已读/状态刷新逻辑。
4. 职工目录导入报错：查预览接口、部门树自动补齐逻辑和同名部门路径冲突。
5. 教师邀请码不可用：查统一邀请码状态、管理员写入权限、工号目录状态与单工号失败锁定。
6. 验证码/通知配置保存成功但通道不可用：继续看 `43` 的后端配置与外发通道文档。

## 验证与回归关注点

- 系统配置改动至少回归：读取、保存、刷新后回显、权限显隐。
- 客服工作台改动至少回归：列表、详情、回复、指派、状态切换、内部备注、在线状态。
- 涉及职工目录或部门树时回归：导入预览、正式导入、批量删除、路径冲突提示；统一邀请码还应回归状态读取、设置/修改后的输入清空、禁用与权限显隐。
- 账号生命周期改动至少回归：双域预检与阻断、注销强制停用、恢复后仍停用、Web/Mobile/SSE 撤销、教师 `staffNo` 身份保留、永久删除失败审计及不可变事件留痕。
