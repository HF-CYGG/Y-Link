# onebox 验收与订单性能修复计划

> 工程执行：采用当前会话内的 GPT-6 Sol 工程子智能体分步实施，主线负责边界、证据复核和验收。遵守用户主线不编码及禁止 worktree 的要求；计划仅定义职责、业务不变量和验收场景。

**目标：** 修复 2026-10-05 onebox 检查确认的验收工具失配与两个订单页面分包体积超限，并在隔离环境中重新执行完整门禁。

**实施方式：** 优先让验收脚本对齐已核实的当前接口、实体和前端行为；性能优化保持订单业务逻辑不变，不调高预算。工程写入与构建验证分阶段交接，独立审查直接检查最终 diff 和运行证据。

**技术栈：** Vue 3、TypeScript、Element Plus、Vite、Express、TypeORM、SQLite、现有 npm 验证脚本及 onebox Docker。

**当前进度：** 前后端实现已冻结。后端 15 个相关去重命令最新结果均为 0；前端完整性能、最终发布功能、7 项专项、编码及 diff 检查通过。独立审查者已逐项核验后端 13 个、前端 14 个修改及新增文件 SHA256，源码无阻断发现。新 onebox 镜像构建、镜像内产物及 111/111 步真实 Docker HTTP 验收通过，匿名桌面/390px 手机 UI 观察完成。开单页 30.79 KB、列表页 28.93 KB；实际总产物 4,679,678 bytes，相对原预算仅余 2 bytes，后续构建必须重新核验。现有 8090 健康且尚未替换，具体部署审批已向用户提出。汇总入口：`tmp/onebox-fix-20261005-report.md`。
